측정 데이터

파일지점측정 시간줄판정

데이터 올리는 법

  1. 측정 후 노트북에서 원본을 정제 CSV로 변환합니다.
    node scripts/clean-logger.ts water_data/2026-11-06/20261106_103000_P1.csv --site P1
  2. 만들어진 파일(예: 2026-11-06_P1_1030.csv)을 GitHub 저장소의 data/clean/ 폴더에 올리고 Pull Request를 만듭니다.
  3. 자동 검사(✓)가 통과하면 메인테이너가 머지합니다.
  4. 봇이 판정과 AI 보고서를 만들어 보고서 PR을 엽니다. 메인테이너가 확인하고 머지하면 이 사이트에 반영됩니다.

정제 CSV 형식

열필수설명
time필수측정 시각 2026-11-06T10:30:00, 시간순
site필수지점 이름(영문·숫자), 파일 이름의 지점과 같아야 함
temp_c · turb_ntu · ec_uS_cm필수수온 °C · 탁도 NTU · 전도도 µS/cm
tds_ppm · level_mm · ph선택비워도 됨 (pH는 보정 전까지 빈칸)
lat · lon선택GPS 위치
